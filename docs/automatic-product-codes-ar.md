# شفرة المنتج التلقائية — V11

عند إنشاء منتج من الواجهة، تُنشأ شفرته تلقائيًا بعد نجاح الحفظ، مثل PRD-00000001. لا تدخل الشفرة يدويًا. الباركود الافتراضي Code 128، ويمكن اختيار Code 39 أيضًا. الشفرات السابقة تبقى كما هي، وحقل الشفرة للقراءة فقط في الواجهة.

الترقيم مركزي في قاعدة البيانات لتجنب التكرار عند الحفظ المتزامن. يتجاوز الشفرات الموجودة، وقد تظهر فجوات عند إلغاء عملية أو فشل التحقق؛ الرقم ليس عدّاد عدد المنتجات.

للتوافق مع سكربتات الاستيراد والبيانات التجريبية، يظل API يقبل شفرة صريحة صالحة. إذا لم ترسل شفرة عند الإنشاء يولدها الخادم؛ وإذا أغفلتها عند تعديل منتج يحتفظ بشفرته الحالية.

## تصحيح الترجمة

«في الأوراق المالية» كانت ترجمة خاطئة لـ In stock. استُبدلت بـ «الكمية المتوفرة في المخزون»: إجمالي كمية المنتج في المخازن بوحدة المنتج، وليست قيمة مالية. إنشاء المنتج وحده لا يضيف مخزونًا؛ تُضاف الكميات من الاستلام أو المشتريات أو الرصيد الافتتاحي حسب العملية.

## التثبيت

```bash
unzip -o ~/Downloads/mpos-auto-product-code.zip -d ~/Storage/mpos-testing
cd ~/Storage/mpos-testing/mpos-architecture
bash scripts/upgrade-imports.sh
```

الحزمة تراكمية وتحتوي على التحديثات السابقة. السكربت يأخذ نسخة احتياطية قبل الترقية. بعدها اضغط Ctrl+Shift+R.

جرّب إنشاء منتجين، وتأكد من اختلاف الشفرتين وظهور الباركود. عدّل اسم أحدهما وتأكد من ثبات شفرته. المنتجات السابقة لا تتغير شفراتها.
