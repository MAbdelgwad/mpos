# النسخة الاسترشادية MPOS

تضاف البيانات عبر REST API بعد تشغيل البرنامج. الحزمة لا تحتوي قاعدة بيانات فعلية أو كلمات مرور أو بيانات عملاء حقيقيين. لا يلزم تشغيل Laravel أو استيراد SQL يدويًا.

## التشغيل

```bash
unzip -o ~/Downloads/mpos-demo.zip -d ~/Storage/mpos-testing
cd ~/Storage/mpos-testing/mpos-architecture
bash scripts/start-demo.sh
```

يفحص السكربت الخدمات أولًا ثم يحمّل البيانات. استخدم http://localhost:18181 لتسجيل الدخول بالحساب الحالي. يقرأ سكربت التحميل بيانات الاعتماد من .env ولا يطبعها. إذا غيرت كلمة المرور داخل التطبيق، حدّث MPOS_ADMIN_PASSWORD في .env لتوافقها قبل التشغيل، كما يلزم لفحص الدخول المعتاد.

لا تُحذف بياناتك الحالية ولا تعدّل إعدادات الشركة أو حساباتك. تُضاف سجلات بأسماء تبدأ بـ[تجريبي] وأكواد DEMO-P001 إلى DEMO-P012. هذه الإضافة تتم داخل قاعدة مشروع mpos-test-architecture الحالية، وليست قاعدة منفصلة تلقائيًا. لا تستخدم down -v. راجع أو احفظ تعديلاتك الخاصة على ملفات المصدر قبل فك ZIP فوقها.

## المنتجات والرموز

أرز، سكر، زيت، شاي، قهوة، مياه، عصير، حليب، صابون سائل، مناديل، عدس وفلفل أسود. وحدات قطعة وعبوة وكيلوجرام، بنسبة 1:1؛ لا يوجد تحويل تلقائي للكرتونة إلى قطع. يتضمن بيع الفرع أوزانًا كسرية لتجربة الكيلوجرام.

يفتح الكتالوج القابل للطباعة من:
http://localhost:18181/images/demo/index.html

ويمكن فتح frontend/images/demo/index.html مباشرة كملف محلي. يحتوي كل ملصق باركودًا وQR يحملان كود المنتج نفسه. QR ليس فاتورة إلكترونية أو رابطًا؛ والـPOS لم يكتمل بعد. باركود المنتج موجود أيضًا في حقل barcode_image_url الذي يولده الباك إند. يمكن فتح ملفات SVG منفردة من المجلد نفسه.

## تدفق البيانات

PUR-01 يضيف 50 وحدة لكل منتج إلى المخزن الرئيسي، وPUR-02 يضيف 25 إلى فرع جدة. المشتريات المعلقة وطلبات الشراء لا تؤثر على المخزون. ثلاث مبيعات مكتملة تخصم إجمالي 28 وحدة موزعة على المنتجات (مع أوزان كسرية)؛ إجمالي الأرصدة الحسابي بعد التحميل 872 عبر 24 رصيدًا. لا تمثل هذه الأرقام قيمة مالية مجمعة أو وحدة قياس واحدة؛ راجع كل منتج بوحدته.

PUR-01 مسدد جزئيًا، PUR-02 بالكامل، SAL-01 بالكامل، SAL-02 جزئيًا، SAL-03 غير مسدد، والمسودات غير مسددة. افتح عرض المستند لمراجعة الدفعات. لا تتحرك أموال فعلية.

## إعادة التحميل

```bash
python3 scripts/seed-demo.py
```

تُعاد الاستفادة من البيانات الموجودة بعلاماتها، وتُستخدم مفاتيح منع التكرار لإنشاء المستندات والدفعات. إن انقطع الاتصال، أعد نفس الأمر من المجلد نفسه؛ اختُبر الانقطاع بعد حفظ فاتورة قبل استلام ردها. السجل الملغى أو الدفعة المعكوسة لا يعاد تنشيطهما. لا تعدّل علامات الملاحظات أو أكواد DEMO إذا أردت أن يتعرف السكربت عليها. لا تشغّل محمّلين متزامنين من جهازين أو مجلدين مختلفين. إذا عدّلت اسمًا أو علاقة أساسية لسجل تجريبي قد يتوقف السكربت عن المتابعة بدل تغيير تعديلك.

للتشخيص: bash scripts/logs.sh api أو bash scripts/collect-logs.sh. التحميل ليس معاملة واحدة لكل البيانات؛ ينفذ معاملات صغيرة قابلة للاستئناف. قد تظهر سجلات جزئية إذا فشل قبل الانتهاء، ويُستأنف عند إعادة التشغيل.

## التحقق المنفذ

اختُبر على نسخة Spring المجمعة وقاعدة PostgreSQL 14.22 مؤقتة: 12 منتجًا، 4 مشتريات، 5 مبيعات، 4 دفعات، إجماليات الفواتير، 24 رصيدًا و34 حركة مخزون، وإعادة التشغيل دون تكرار مع الحفاظ على سجل سابق غير تجريبي. تحققت قراءة رموز QR وCode 128 بواسطة ZXing. نجح بناء الواجهة مع التحذيرات السابقة. تشغيل حزمة Docker وتجربة الطباعة/الماسح على جهازك يحتاجان تحققًا محليًا. لا يضيف هذا الإصدار POS أو مرتجعات أو تقرير أرباح.
